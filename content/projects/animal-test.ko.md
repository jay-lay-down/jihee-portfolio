## 요약
메타인지와 상황판단 패턴을 기반으로, 실제 사회생활 속 행동을 11가지 "사회적 동물" 유형으로 시각화하는 인터랙티브 웹 테스트입니다. 문항 설계, 채점 알고리즘, UI, 배포까지 전 과정을 직접 만들었습니다.

## 기술 스택
Python · Gradio · HTML/CSS · Hugging Face Spaces

## 성과
- 자체 채점 알고리즘과 반응형 UI 구축
- 자체 도메인 `myanimaltest.site` 연결
- 사용자 응답을 수집·분석할 수 있는 라이브 서비스로 구현
