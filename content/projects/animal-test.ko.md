## 개요
실제 사회생활 속 행동 패턴을 11가지 "사회적 동물" 유형으로 시각화하는 인터랙티브 웹 테스트입니다. "나는 눈치가 빠르다고 생각하는데, 왜 사람 관계는 항상 꼬일까?"라는 흔한 고민을 데이터와 알고리즘으로 풀어본 개인 프로젝트입니다.

## 심리학적 프레임
단일한 "사회성 점수"가 아니라 서로 다른 두 축으로 설계했습니다:

- **메타인지** (Flavell, 1979) — 내가 타인에게 어떻게 보이는지, 무엇을 알고 모르는지 아는 능력
- **상황 판단력** (Thorndike의 사회지능, 1920) — 지금 무슨 일이 일어나는지, 상대의 의도·타이밍·맥락을 읽는 능력

"실수는 본인이 제일 모르고 주변은 다 안다"는 더닝-크루거의 비대칭이 바로 이 두 축의 간극이며, 11가지 유형은 두 축 위 위치의 조합입니다.

## 프로덕트 설계
- 문항 설계와 자체 채점 알고리즘 개발 — 응답 패턴을 두 축 점수로, 다시 11개 유형으로 매핑
- Gradio 기반 UI에 CSS 커스터마이징과 동적 HTML 결과 카드를 얹어 구현
- 프라이버시 우선 설계: 성별/연령대/문항 응답 외에는 아무것도 저장하지 않음

## 배포
Hugging Face Spaces에 배포하고 자체 도메인(`myanimaltest.site`)을 연결 — 사용자 응답을 수집·분석할 수 있는 라이브 서비스로 운영 중입니다.
