## 요약
비즈니스·리서치 질문에 답하는 셀프호스팅 분석 챗봇입니다. 유료 API 없이 오픈소스 LLM을 페르소나 파인튜닝하고, 경량 배포에 최적화했습니다.

## 기술 스택
Python · PyTorch · Transformers · QLoRA · Hugging Face Hub · Gradio

## 성과
- 분석·리서치 용도에 맞춘 페르소나 정렬 어시스턴트 파인튜닝 (QLoRA 4bit 양자화)
- 양자화로 서빙 비용을 낮춰 셀프호스팅 배포 구현
- 대화형 분석 워크플로를 체험할 수 있는 라이브 데모 공개
